# Intégrations de connexion de l’agent de développement Adobe Commerce

Le code généré a besoin d’un emplacement pour s’exécuter et d’une connexion à votre boutique. Cette étape intègre tous les éléments (hébergement du code dans App Builder, connexion à votre instance Adobe Commerce et liaison d’un référentiel GitHub) avant l’activation de la fonctionnalité.

## À qui s&#39;adresse cette vidéo ?

* Développeurs Commerce
* Architectes de solutions
* Ingénieurs ou ingénieures back-end

## Contenu vidéo

* Créer un projet App Builder et un espace de travail pour héberger le code créé par l’agent de développement
* Observer le modèle automatique de l&#39;agent pour le projet et faire apparaître les éléments de configuration en attente
* Ajout des informations d’identification d’API Adobe Commerce as a Cloud Service requises dans Developer Console
* Connexion du code à une instance Adobe Commerce Cloud Service spécifique
* Pour stocker et modifier la version du code, liez un référentiel GitHub
