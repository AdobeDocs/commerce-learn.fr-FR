# Présentation de l’agent de développement Adobe Commerce

L’agent de développement Adobe Commerce transforme une requête en anglais simple en une fonctionnalité de magasin opérationnelle et déployée, sans code écrit à la main. Cette présentation suit le parcours complet, d’une instruction saisie unique à un test en direct sur un véritable storefront, et explique pourquoi cela modifie la manière dont les fonctionnalités Commerce personnalisées sont créées.

## À qui s&#39;adresse cette vidéo ?

* Développeurs Commerce
* Architectes de solutions
* Chefs de file du développement

## Contenu vidéo

* Pourquoi les fonctionnalités Commerce personnalisées nécessitent-elles généralement du code webhook manuscrit, une configuration App Builder et un cycle de build-test-déploiement complet ?
* La façon dont l’agent de développement gère la mise en œuvre technique (la méthode webhook correcte, le mappage de la payload et le schéma de configuration) à partir d’une règle en anglais simple
* Validation automatique du code qui intercepte et corrige les erreurs de version avant qu’un utilisateur ouvre un débogueur
* Exposer les limites et les messages comme configuration commerciale que l’équipe du magasin peut ajuster après le lancement
* Aperçu de la présentation complète : plan directeur, développement, connexion, déploiement, configuration et test
