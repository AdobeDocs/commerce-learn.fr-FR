# Mise en œuvre de l’architecture de référence globale

{{only-for-on-prem-commerce-cloud}}

Découvrez comment mettre en œuvre l’architecture de référence globale (GRA). Découvrez les premières décisions qui permettent de configurer une GRA performante. Obtenez des idées sur la manière de séparer vos sites web, les clés du succès et certains concepts pour développer des fonctionnalités de manière organisée.

## Audience

* Toute personne ayant besoin de comprendre ce concept.
* Projets volumineux avec plusieurs marques

## Contenu vidéo

* Des décisions précoces sont essentielles pour une GRA réussie
* Idées pour distribuer des sites web dans un GRA
* Les clés du succès d’un projet d’architecture de référence mondiale
* Conventions de dénomination
* Choisir la marque ou le site Web approprié pour l’ensemble des fonctionnalités de base
* Rôles et responsabilités clés
* Tableau de contrôle global : sur quelles fonctionnalités travailler
* Concept alternatif pour utiliser GRA comme marketplace de module
