# Utilisation d’Adobe Experience League pour créer un ticket d’assistance

Découvrez comment créer un ticket d’assistance dans Adobe Experience League pour Adobe Commerce.

## À qui s&#39;adresse cette vidéo ?

* Personnes ayant la possibilité de créer des demandes d’assistance pour Adobe Commerce dans Adobe Experience League

## Contenu vidéo {#video-content}

* Découvrez comment vous connecter à Adobe Experience League
* En savoir plus sur les éléments de formulaire dynamiques lors de la création d’un ticket de support
* Découvrez comment les articles recommandés changent en fonction des informations utilisées dans le formulaire
* Comment le texte d’espace réservé figurant dans les champs du formulaire permet de comprendre le type d’informations nécessaires à une bonne demande d’assistance
