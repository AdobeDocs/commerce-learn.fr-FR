# Automatisation de l&#39;application de correctifs Adobe Commerce

L&#39;automatisation des correctifs d&#39;Adobe Commerce est une fonctionnalité de l&#39;outil d&#39;analyse de l&#39;ensemble du site (SWAT) d&#39;Adobe Commerce qui simplifie le processus de découverte et d&#39;application de correctifs de sécurité. Les utilisateurs accèdent à l’automatisation des correctifs via l’administration Commerce, sous le tableau de bord SWAT, sélectionnent leur projet et leur environnement, puis affichent les correctifs disponibles.
